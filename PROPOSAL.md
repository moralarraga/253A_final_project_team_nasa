Idea:
This project is called the NASA Time Capsule. We will use a publicly available dataset from NASA. This data gives us access to images for a given date. The plan is to have a home page where the user can click “On This Day,” which prompts a random year for the specific date they access the site.  Or they can click “On This Day,” then enter a date or keyword.  They can access anything they want, from planets to people to random locations. 


API:
Nasa Image/Video API: https://images-api.nasa.gov
We ended choosing this external API, because it's publicly available, has a very large data set, and allows for different requests from the user. Also it’s 1,000 requests per hour, so that allows for a large amount of users and the ability for them to retrieve ample information.
